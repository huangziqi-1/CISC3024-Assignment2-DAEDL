# CISC3024 AI Assignment #2: Density Aware Evidential Deep Learning

This repository is the working area for an AI-assisted investigation and implementation of Density Aware Evidential Deep Learning (DAEDL), published at ICML 2024. The project focuses on CIFAR-10 classification, probability calibration, uncertainty on errors and corrupted inputs, and a manageable out-of-distribution test.

Current status: Phase 3B frozen Softmax and DAEDL replications at seeds 3024, 3025, and 3026 are complete and validated. See [PHASE3B_RESULTS.md](PHASE3B_RESULTS.md). Corruptions, EDL, CIFAR-100 OOD, final report generation, and publication have not been started.

## Reproducibility policy

- Every reported number must come from a saved machine-readable result file.
- Every table and figure must be generated by a script.
- Dataset splits, seeds, model settings, package versions, device, and runtime must be saved with each run.
- Paper-reported results and locally measured results must be clearly distinguished.
- Large datasets, checkpoints, caches, and generated outputs are excluded from Git.

See [PLANNING_REVIEW.md](PLANNING_REVIEW.md), [AI_USAGE_LOG.md](AI_USAGE_LOG.md), and [references/SOURCES.md](references/SOURCES.md).

## Planned workflow

1. Phase A: dependency and pipeline smoke test on a small stratified subset for 1-2 epochs.
2. Phase B: one-seed pilot comparing Softmax, EDL, and DAEDL.
3. Phase C: final multi-seed runs only after inspecting pilot runtime and trends.

## Environment setup

```bash
/Library/Frameworks/Python.framework/Versions/3.11/bin/python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip install --no-build-isolation -e .
MPLCONFIGDIR=.cache/matplotlib .venv/bin/python -m pytest
```

The validated host environment uses Python 3.11.5, PyTorch 2.14.1, torchvision 0.29.1, and Apple MPS for training. DAEDL post-training inference and density fitting currently use CPU because the spectral-normalized model produced NaN embeddings on the PyTorch 2.14.1 MPS evaluation path. See [PILOT_SUMMARY.md](PILOT_SUMMARY.md).
